# Global Encounters Food App

A React Native app used by staff at the Global Encounters event to scan participant QR codes and record meal distribution.

## Context

Works with the Global Encounters Food API (FastAPI + PostgreSQL).

## Features

- Staff login with auth context
- QR code scanner to look up a participant
- Find volunteer/participant screen and volunteer registration modal
- Settings screen; splash screen and app icons

## Tech stack

- **Mobile:** React Native, React Navigation
- **QR:** react-native-qrcode-scanner, react-native-camera
- **HTTP:** axios

## Getting started

```bash
yarn install
yarn start
yarn android
```
